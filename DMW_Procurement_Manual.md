## 2. System Overview

The DMW Procurement Plan System is an integrated desktop application for regional procurement planning, transaction tracking, inventory control, and document monitoring. It supports the Department of Migrant Workers Regional Office XIII procurement lifecycle, including planning, procurement, inspection, and submission workflows.

## 14. System Reference for Leaders

This section is written for department leaders and non-IT stakeholders. It summarizes the main pages and actions in the system using clear labels, and it includes the exact application routines only so technical staff can locate the behavior if needed.

- PPMP (Project Procurement Management Plan)
  - Load the PPMP page and refresh PPMP data: `loadPPMP()`
  - Open the dialog to add a new PPMP item: `showNewPPMPModal(preSelectSource)`
  - Save a newly created PPMP item: `saveNewPPMP(event)`
  - Open the dialog to edit an existing PPMP item: `showEditPPMPModal(planId)`
  - Save updates to an existing PPMP item: `submitEditPPMP(event, planId)`
  - Open the catalog selector when choosing items for PPMP: `showPPMPCatalogItemModal()`
  - Open the catalog selector while editing PPMP items: `showEditPPMPCatalogItemModal()`
  - Change the procurement source in the create form: `togglePPMPSourceMode(source)`
  - Change the procurement source in the edit form: `toggleEditPPMPSourceMode(source)`
  - Recalculate estimated budget for manual PPMP entries: `calcEditManualEstBudget()`
  - Recalculate estimated budget for PAP entries: `calcEditPAPEstBudget()`
  - Keep PAP title and description aligned while creating PPMP: `syncNewPAPNameWithDescription(value)`
  - Keep PAP description and general details aligned while creating PPMP: `syncNewPAPDescWithGeneral(value)`
  - Keep manual item name and description aligned while editing PPMP: `syncManualNameWithDescription(value)`
  - Keep manual item description and general details aligned while editing PPMP: `syncManualDescWithGeneral(value)`

- APP (Annual Procurement Plan)
  - Load the APP page and display the annual procurement summary: `loadAPP()`
  - Load APP status for a specific year: `loadAPPStatus(year)`
  - Open the dialog to edit an APP entry: `showEditAPPModal(planId)`
  - Save changes to an APP entry: `submitEditAPP(event, planId)`
  - Submit APP version status changes: `submitAPPStatus(event)`

- PR (Purchase Request)
  - Load the Purchase Request page: `loadPR()`
  - Open the new Purchase Request dialog: `showNewPRModal()`
  - Save a new Purchase Request: `saveNewPR(event)`
  - Open the edit dialog for a Purchase Request: `showEditPRModal(id)`
  - Save changes to a Purchase Request: `saveEditPR(event, id)`
  - Save a Purchase Request draft without submitting: `saveEditPRDraft(event, id)`
  - Submit an edited Purchase Request for approval: `submitEditPRForApproval(id)`
  - Submit a new Purchase Request for approval: `submitPRForApproval()`

- RFQ (Request for Quotation)
  - Load the RFQ page: `loadRFQ()`
  - Open the new RFQ dialog, optionally linked to a PR: `showNewRFQModal(preselectedPrNumber)`
  - Save a new RFQ: `saveNewRFQ(event)`
  - Open the RFQ edit dialog: `showEditRFQModal(id)`
  - Save changes to an RFQ: `saveEditRFQ(event, id)`
  - Send RFQ requests to suppliers: `sendRFQ()`

- AOQ (Abstract of Quotations)
  - Load the AOQ page: `loadAbstract()`
  - Open the new AOQ dialog: `showNewAbstractModal()`
  - Save a new AOQ record: `saveNewAbstract(event)`
  - Open the AOQ edit dialog: `showEditAbstractModal(id)`
  - Save changes to an AOQ record: `saveEditAbstract(event, id)`
  - Submit finalized AOQ documents: `submitAbstract()`

- Post Qualification

  - Open the new Post Qualification record dialog: `showNewPostQualModal()`
  - Save a new Post Qualification entry: `saveNewPostQual(event)`
  - Open the edit dialog for a Post Qualification entry: `showEditPostQualModal(id)`
  - Save changes to a Post Qualification entry: `saveEditPostQual(event, id)`
